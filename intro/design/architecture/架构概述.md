### 双层架构：REPL 外层 + LangGraph 执行内层

**REPL 外层（main.py 直接调用，非 LangGraph 节点）：**

| 组件 | 类型 | 职责 |
|------|------|------|
| **UserCoordinator** | LLM (Thinker+Formatter) | 人机协作网关：意图分类 → 三级渐进式确认 → IS_EXECUTE 闸门。输出五字段（CHAT_MESSAGE, SOP_ID, CURRENT_ACTION, LONG_TERM_INTENT, IS_EXECUTE）。同时负责 SOP 匹配（v2 合并了原 InitialSOPRetriever 的职责） |
| **TaskCompactor** | LLM (Thinker+Formatter) | SOP 执行评价 + 对话/执行历史压缩。每次 SOP 执行完毕后运行。输出 EVALUATION, CONVERSATION_SUMMARY, EXECUTION_SUMMARY → 累积为跨周期长期记忆 |
| **ChatCompactor** | LLM (Thinker+Formatter) | 对话上下文压缩。手动 `/compact` 或 token>4096 自动触发。输出 CONVERSATION_SUMMARY → 追加到 conversation_history |
| **TTS 引擎** | 服务（非 LLM） | 基于 Microsoft Edge TTS 的语音播报。Agent 结论性回复通过 ffplay 朗读，支持 8 种语音选择、语速调节。异常静默降级 |

**LangGraph 执行内层（3 节点循环）：**

| 节点 | 类型 | 职责 |
|------|------|------|
| **SOP Execution Scheduler** | LLM (Thinker+Formatter) | 扫描 SOP_PLAN 进度标记 → 定位下一步 → 输出 TOOL_CALL + TASK_STATUS |
| **ToolExecutor** | Data Node | 分发工具调用；detail 非空时存入 VariableStore（变量名 `VAR_{TOOL_ID}`） |
| **ProgressUpdater** | Data Node (纯代码) | 机械追加进度标记到 SOP_PLAN（顺序/条件/并行/重试 4 种模式） |

> **注意**：v2 重构后，SOP 匹配与加载已从 InitialSOPRetriever（LangGraph 节点）移至 REPL 外层。UserCoordinator 负责意图分类时匹配 SOP_ID，main.py 直接调用 `load_sop_markdown()` 加载。`llm_nodes/InitialSOPRetrieverNode.py` 和 `prompts/initial_sop_retriever/` 为 v1 遗留，不再使用。

### REPL 主循环流程

```
用户输入 → UserCoordinator（意图分类 + 渐进确认）
  ├── IS_EXECUTE="false" → 显示 CHAT_MESSAGE → 继续对话
  └── IS_EXECUTE="true"  → 用户最终确认(y/n)
        └── y → 加载SOP → LangGraph执行图 → Compactor(评价+压缩)
                → 满意? → 累积历史摘要 + 清除对话 → 下一轮
```

### REPL 命令

使用 `/` 前缀，在 UserCoordinator 之前拦截，不消耗 LLM：`/help` `/sops` `/config` `/clear` `/compact` `/resume` `/exit`。确认流程（`y`/`n`）不加前缀。

- `/help`：显示所有可用命令和简要说明
- `/sops`：打开 SOP 选择器，可视化浏览并勾选要启用的 SOP（多选，Enter 确认/Esc 取消）
- `/config`：打开全局设置选择器，可调整压缩阈值、流式缓冲间隔、TTS 参数等，修改后自动持久化
- `/compact [提示]`：手动触发 ChatCompactor 压缩对话上下文，可附带压缩要求
- `/resume [session_id]`：无参数时打开会话选择器；带 session_id 参数时直接恢复指定会话
- `/clear`：保存当前会话并创建新会话
- `/exit`：退出 REPL（自动保存会话）

Tab 补全由 prompt_toolkit 的 `ReplCompleter`（`repl/command_handler.py`）提供，支持命令名和子参数两级补全。方向键光标移动和汉字删除由 prompt_toolkit `TextArea` 控件原生支持。

### 流式输出

所有 LLM 调用（节点 Thinker + Formatter、工具 LLM）均通过 `utils/streaming.py` 的 `stream_llm()` 实现 token 级流式输出，实时打印到终端。

### 多选择器系统

REPL 底部区域通过 `ConditionalContainer` + `any_picker` 复合过滤器支持三种选择器的动态切换：

| 选择器 | 触发命令 | 用途 | 高度 |
|--------|---------|------|------|
| Session Picker | `/resume`（无参数） | 浏览并恢复历史会话 | 8 行 |
| SOP Picker | `/sops` | 多选勾选要启用的 SOP | 动态 |
| Config Picker | `/config` | 调整运行时配置参数 | 11 行 |

三种选择器通过 `any_picker = picker_filter | sop_picker_filter | config_picker_filter` 确保同一时刻只有一个可见。正常状态下底部显示状态栏（含 token 信息），任一选择器激活时状态栏自动隐藏。

### 打包与全局命令

项目通过 `pip install -e .`（editable install）安装，`pyproject.toml` 定义 `[project.scripts]` 入口点 `cutin = "main:main"`。pip 生成的脚本使用 venv 的绝对 shebang，无需手动激活虚拟环境。`~/.local/bin/cutin` 符号链接使 `cutin` 命令全局可用。

所有文件 I/O 路径通过 `__file__` 推导 `_PROJECT_ROOT` 后拼接，保证从任意 CWD 启动都能正确找到 prompts、config、sessions、history 等资源目录。
