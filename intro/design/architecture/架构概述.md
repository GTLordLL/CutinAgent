### 双层架构：REPL 外层 + LangGraph 执行内层

**REPL 外层（main.py 直接调用，非 LangGraph 节点）：**

| 组件 | 类型 | 职责 |
|------|------|------|
| **UserCoordinator** | LLM (Thinker+Formatter) | 人机协作网关：意图分类 → 三级渐进式确认 → IS_EXECUTE 闸门。输出五字段（CHAT_MESSAGE, SOP_ID, CURRENT_ACTION, LONG_TERM_INTENT, IS_EXECUTE） |
| **TaskCompactor** | LLM (Thinker+Formatter) | SOP 执行评价 + 对话/执行历史压缩。输出 EVALUATION, CONVERSATION_SUMMARY, EXECUTION_SUMMARY → 累积为跨周期长期记忆 |
| **ChatCompactor** | LLM (Thinker+Formatter) | 对话上下文压缩。手动 /compact 或 token>4096 自动触发。输出 CONVERSATION_SUMMARY → 追加到 conversation_history |

**LangGraph 执行内层（3 节点循环）：**

| 节点 | 类型 | 职责 |
|------|------|------|
| **SOP Execution Scheduler** | LLM (Thinker+Formatter) | 扫描 SOP_PLAN 进度标记 → 定位下一步 → 输出 TOOL_CALL + TASK_STATUS |
| **ToolExecutor** | Data Node | 分发工具调用；detail 非空时存入 VariableStore（变量名 `VAR_{TOOL_ID}`） |
| **ProgressUpdater** | Data Node (纯代码) | 机械追加进度标记到 SOP_PLAN（顺序/条件/并行/重试 4 种模式） |

> **注意**：v2 重构后，SOP 匹配与加载已从 InitialSOPRetriever（LangGraph 节点）移至 REPL 外层。UserCoordinator 负责意图分类时匹配 SOP_ID，main.py 直接调用 `load_sop_markdown()` 加载。`llm_nodes/InitialSOPRetrieverNode.py` 和 `prompts/initial_sop_retriever/` 为 v1 遗留，不再使用。

### REPL 主循环流程

```
用户输入 → UserCoordinator（意图分类 + 渐进确认）
  ├── IS_EXECUTE="false" → 显示 CHAT_MESSAGE → 继续对话
  └── IS_EXECUTE="true"  → 用户最终确认(y/n)
        └── y → 加载SOP → LangGraph执行图 → Compactor(评价+压缩)
                → 满意? → 累积历史摘要 + 清除对话 → 下一轮
```

### REPL 命令

使用 `/` 前缀，在 UserCoordinator 之前拦截，不消耗 LLM：`/help` `/sops` `/history` `/clear` `/compact` `/resume` `/exit`。确认流程（`y`/`n`）不加前缀。

- `/compact [提示]`：手动触发 ChatCompactor 压缩对话上下文，可附带压缩要求
- `/resume [session_id]`：无参数时打开会话选择器；带 session_id 参数时直接恢复指定会话
- `/clear`：保存当前会话并创建新会话
- `/exit`：退出 REPL（自动保存会话）

通过 `import readline` 提供 Tab 命令补全、汉字正确删除、方向键光标移动。`readline.set_completer_delims(" \t\n")` 确保 `/` 被视为命令名的一部分。

### 流式输出

所有 LLM 调用（节点 Thinker + Formatter、工具 LLM）均通过 `utils/streaming.py` 的 `stream_llm()` 实现 token 级流式输出，实时打印到终端。
